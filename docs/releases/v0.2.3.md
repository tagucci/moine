# mòine v0.2.3

`v0.2.3` refreshes the SudachiDict-full download target and strengthens lattice
edit-distance test coverage.

## Highlights

- Rust and Python `download ja-sudachi` now install the SudachiDict-full
  `20260723` artifact instead of `20260428`. The new index contains 2,310,387
  entries, with the same reading filters and bounded expansion settings.
- Property tests check lattice distance against an independent exhaustive
  path-pair reference, compact/plain lattice equivalence, symmetry, self-distance,
  cutoff behavior, and edit traces. Deterministic tests cover empty paths.

## Compatibility

Public APIs, distance algorithms, and dictionary payload formats are unchanged.
Comparisons using the refreshed Sudachi dictionary may produce different scores
because its entries and readings have changed. Existing explicitly loaded
bundles remain usable.

The `ja` / `ja-unidic` and `zh` download targets are unchanged:

- UniDic-CWJ: `unidic-cwj-202512-v0.1.1`
- SudachiDict-full: `moine-sudachi-full-20260723-v0.2.0`
- CC-CEDICT: `moine-cedict-20260520-v0.1.1`

The Sudachi dictionary release is already published, with public-URL downloads
verified in Rust and Python. See the [artifact release notes](moine-sudachi-full-20260723-v0.2.0.md)
for checksums and reproduction steps.
