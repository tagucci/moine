# mòine v0.2.2

`v0.2.2` is a performance and release-hardening update. It does not change the
dictionary payload formats or the public downloader targets.

## Highlights

- Indexed Japanese and Chinese artifacts retain their backing bytes instead of
  reconstructing payload storage during load.
- Direct Japanese romaji lattices are built as compact DAGs without first
  enumerating every romaji variant. Explicit path callers can use
  `RomajiExpansionLimits` and `romaji_paths_with_limits` for bounded expansion.
- Normalized reading-path comparison tokenizes each retained path once and
  reuses distance workspaces across candidate pairs.
- Python `extract_one` selects the best candidate in one pass while preserving
  input-order tie behavior.
- Package-version/tag checks and installed-wheel tests cover the release
  artifacts across supported Python versions on Linux, macOS, and Windows.

## Bounded dictionary expansion

Dictionary-backed comparisons remain bounded by settings such as `max_paths`,
`max_readings_per_segment`, `max_span_chars`, and `longest_only`. A score is
exact for the retained reading paths. When a limit prunes candidates, the score
may differ from an exhaustive expansion, and candidate retention order should
not be interpreted as a frequency or probability ranking.

## Dictionary artifacts

The release continues to use the existing public artifacts:

- UniDic-CWJ `v0.1.1`
- SudachiDict-full `v0.2.0`
- CC-CEDICT `v0.1.1`

No dictionary payload or artifact-specific release tag is changed by this
package release.
